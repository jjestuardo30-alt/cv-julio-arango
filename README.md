
# CV Web — Julio Arango

Este proyecto es un currículum web desarrollado como parte de la asignatura de HTML y CSS.  
Incluye diseño responsive, animaciones CSS, navegación mediante `:target`, modo impresión y estilos accesibles.

## Tecnologías utilizadas

- HTML5 semántico  
- CSS3 (flexbox, grid, variables, animaciones, pseudo-elementos)  
- Responsive design (mobile-first)  
- Modo impresión con `@media print`  
- Navegación sin JavaScript usando `:target`  

---

 # Estructura del proyecto


### `index.html`
- Contiene toda la estructura semántica del CV.  
- Incluye: sidebar, header, main con secciones, footer.  
- Usa etiquetas semánticas (`header`, `main`, `section`, `footer`, `aside`).  
- Es el archivo que Vercel sirve como página principal.

### `styles.css`
- Hoja de estilos completa del proyecto.  
- Incluye:
  - Variables CSS  
  - Diseño mobile-first  
  - Animación del fondo  
  - Navegación con `:target`  
  - Glassmorphism  
  - Media queries  
  - Modo impresión  
  - Accesibilidad (`a:focus`)  

### `assets/img`
- Carpeta que contiene los recursos gráficos.  
- `foto.jpg`: foto de perfil.
